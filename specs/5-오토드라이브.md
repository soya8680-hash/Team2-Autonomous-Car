# 지시서 5 · 오토드라이브

> **초안:** 사용자 요청(2026-11-04 「다 진행해 줘」)으로 Claude가 숫자와 규칙을 정했다. 조가 아직 확인하지 않았다. 고치려면 이 지시서부터 고치고 `tools/autodrive_core.py`의 `Config`를 맞춘다.

## 목표
프로그램을 한 번 실행하면 손대지 않고 줄 1바퀴 · 장애물 정지 · 사람과 STOP 반응 · 영상과 기록 저장까지 한다.

## 상태표
위에서 아래 순서로 먼저 맞는 줄을 따른다.

| 지금 상태 | 본 것 | 다음 상태 | 행동 |
|---|---|---|---|
| 모두 | 180초 경과 · 카메라 2초 멈춤 · 초음파 1초 고장 · 줄 0.5초 넘게 놓침 | EMERGENCY | 바퀴 0 · 빨간 불 · 삐 1초 · 종료 |
| 모두 | 아무 키 · Ctrl+C · 오류 | 종료 | 바퀴 0 |
| STOP_SIGN | 3초 안 지남 | STOP_SIGN | 바퀴 0 |
| WAIT_OBSTACLE | 20cm 안 됨 | WAIT_OBSTACLE | 바퀴 0 |
| WAIT_PERSON | 사람이 있거나 사라진 지 1초 안 됨 | WAIT_PERSON | 바퀴 0 |
| 주행 | 15cm 이하 | WAIT_OBSTACLE | 바퀴 0 · 파란 불 · 삐 0.2초 |
| 주행 | 사람 가까움 | WAIT_PERSON | 바퀴 0 · 빨간 불 · 삐 0.5초 |
| 주행 | STOP 표지 (재출발 뒤 5초는 무시) | STOP_SIGN | 바퀴 0 · 빨간 불 · 삐 0.2초 |
| 주행 | 출발 5초 뒤 네 칸 모두 검정 3번 연속 | FINISHED | 바퀴 0 · 삐 0.2초 · 기록 |
| 주행 | 줄 잠깐 놓침 | 그대로 | 직전 동작 유지 |
| 주행 | 40cm 이하 또는 사람이 조금 멀리 보임 | SLOW | 속도 45 · 안쪽 25 · 노란 불 |
| 주행 | 그 밖 | FOLLOW | 속도 60 · 안쪽 30 · 초록 불 |

출발 5초 전의 네 칸 모두 검정은 출발선으로 보고 지나간다. 왜 장애물이 STOP보다 먼저인가: 부딪히는 것이 가장 큰 사고이기 때문이다.

## 성공 기준 (숫자로)
- 세 번 중 한 번 이상 완주 · 손댄 횟수 0 · 영상 저장.
- 9회차 기록이 4회차 기록보다 이탈 또는 손댄 횟수가 적음.

## 안전
- 바퀴 속도 60 이하. 코드에 150 초과 거부가 들어 있다.
- 출발 전 삐. 끝나면(오류가 나도) 네 바퀴 0 · 부저와 불빛 끔.
- 실제 주행은 VS Code 터미널에서 직접 실행하고 「확인」을 입력해야 시작한다.

## 바꿔 볼 값
- 줄 놓침 허용 0.5초 → 0.2초: 곡선 이탈과 비상 정지 횟수 비교.

## 실행
- 모의: `python3 missions/5_autodrive.py --simulate` (기록표에 안 남김)
- 실제: `python3 missions/5_autodrive.py --drive --session 7 --attempt 1` → 끝나면 완주와 손댄 횟수를 입력
- 영상은 `results/videos/`, 자세한 기록은 `results/runs/`, 한 줄 기록은 `results/runs.csv`.
