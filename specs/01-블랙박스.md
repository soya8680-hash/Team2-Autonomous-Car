# 지시서 01 · 블랙박스

## 목표
라즈봇 카메라로 영상을 녹화하고 영상 위에 시각·거리·조 이름을 표시한다.
출처: 사용자가 제공한 「라즈봇 자율주행 미션 안내」 1단계. 사용자는 1단계부터 진행하기로 선택했다.

## 규칙표
| 상황 (언제) | 행동 (무엇을) |
|---|---|
| 첫 촬영 시험 | 정지 상태에서 10초 녹화한다. |
| 녹화 중 | 한국 시각과 조 이름 `2조`를 표시한다. |
| 거리 표시 | 초음파 거리를 cm로 표시한다. 읽기에 실패하면 오류로 표시하고 기록한다. |

## 성공 기준 (숫자로)
- 10초 촬영 영상이 10초로 재생된다. 파일 길이와 실제 촬영 시간을 검사한다.
- 사용자가 휴대폰에서 파일을 열어 재생을 확인한다.
- 영상의 시각·조 이름·거리 표시는 사용자 확인 후 검증한다.

## 안전
- 이 단계에서는 바퀴를 움직이지 않는다.

## 바꿔 볼 값
- 조에서 정할 항목: 아직 미정.

## 사용자 확정 내용
- 조 이름: 2조.
- 거리 표시: 예.
- 저장: results/ 아래 MP4 영상. 휴대폰 재생 확인은 사용자가 한다.
