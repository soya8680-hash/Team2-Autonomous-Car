# 지시서 · 15초 자유주행 + 사람 앞 정지

사용자 요청(2026-11-04): 카메라를 사람이 다 보이게 올리고, 15초 동안 달리다 사람이 너무 가까워지면 멈춘다.
속도와 거리 기준은 Claude 초안이다. 실제로 재 보고 조가 고친다.

## 목표
줄 없이 앞으로 가다가 사람이 가까워지면 스스로 멈춘다. 트랙과 초음파 없이 YOLO 반응을 시험한다.

## 규칙표
| 상황 (언제) | 행동 (무엇을) |
|---|---|
| 출발 | 삐 → 1초 뒤 네 바퀴 속도 40으로 직진 · 초록 불 |
| 사람 (점수 0.5 이상 · 상자 높이 300px 이상 · 연속 2번) | 바로 정지 · 빨간 불 · 삐 0.5초 → 끝. 다시 출발하지 않음 |
| 15초 경과 | 정지하고 끝 |
| 카메라나 YOLO 결과가 1초 넘게 멈춤 | 정지하고 끝 |
| 아무 키 · Ctrl+C · 오류 | 정지하고 끝 |

## 성공 기준 (숫자로)
- 사람 앞에서 5번 중 5번 멈춤 · 부딪히지 않음. 실제 거리는 사용자가 재서 적는다.

## 안전
- 바퀴 속도 40.
- **사람 말고는 못 본다.** 초음파를 쓰지 않으므로 벽 · 의자 · 책상 끝 앞에서 멈추지 않는다. 앞쪽 공간을 비우고 바닥에서만 실행한다.
- 사람이 찍히지 않으면 멈추지 않는다. 다가갈 때 카메라 정면에 서고, 언제든 키를 누를 준비를 한다.
- 터미널에서 직접 실행하고 「확인」을 입력해야 시작한다.

## 카메라 각도
좌우 90° · 위아래 40° (사람이 다 보이게 올림). 주행 프로그램은 시작할 때 이 각도로 맞춘다.

## 바꿔 볼 값
- 상자 높이 300px → 200px: 멈추는 거리 비교.

## 실행
- 바퀴 없이: `python3 missions/free_drive.py --dry`
- 실제: `python3 missions/free_drive.py --drive`
