# 지시서 06 · 달리면서 사람·STOP에 반응

> **3조 지시서를 가져옴** (github.com/jihooni217/raspbot-pbl-3team @ 7e8a30d, 2026-11-05). 규칙과 숫자는 3조가 정한 값이고 **2조가 아직 확인하지 않았다.** 아래 「결과」 표의 기존 줄은 3조 기록이며 2조 라즈봇·트랙에서 나온 결과가 아니다.

## 목표
`missions/02_line_follow.py`의 줄 따라가기에 별도 스레드의 YOLO 인식을 붙여, 달리면서 STOP과 사람을 보면 정지하고 정해진 조건에 따라 다시 출발한다.

## 규칙표
| 상황 (언제) | 행동 (무엇을) |
|---|---|
| 줄을 따라 달림 | 기존 02 줄 따라가기 판단을 사용한다. 직진 속도는 50이다. 꺾기 30/60·15/60·0/60, 탐색 0/40을 그대로 유지한다. |
| 카메라 읽기 | `tools/yolo.py`의 `open_camera()`를 사용한다. 카메라 읽기는 한 스레드가 맡아 최신 화면만 공유한다. |
| YOLO 인식 | 주행 반복과 별도 스레드에서 최신 화면을 인식한다. `tools/yolo.py`의 `Detector(size=640)`과 기존 `models/yolo26n_640.onnx`를 사용한다. 모델은 변경하지 않는다. |
| 인식 대상으로 판단 | `stop sign`과 `person`의 점수 0.4 이상을 대상으로 한다. 서로 다른 새 인식 결과에서 대상 종류별로 연속 2회 검출되면 반응한다. 같은 결과를 반복해서 읽은 것은 횟수에 넣지 않는다. |
| 대상이 멀리 있거나 화면 가장자리에 보임 | 위치·크기 조건 없이 반응한다. 대상별 점수와 상자 높이(픽셀)를 기록한다. |
| STOP이 보임 | 네 바퀴를 정지하고 3초 뒤 줄 따라가기를 다시 시작한다. 3초는 정지 명령을 처음 보낸 때부터 센다. 사람이 함께 있으면 사람 정지가 우선한다. |
| STOP 정지 후 다시 출발함 | 출발 뒤 5초 동안 같은 STOP을 무시한다. 이 시간에는 모든 STOP을 무시한다. 5초는 STOP 처리 후 실제 주행 명령이 다시 나간 때부터 센다. |
| 무시 시간 5초가 끝나도 STOP이 계속 보임 | 계속 보이는 STOP에는 재정지하지 않는다. 새 결과에서 연속 1초 안 보였다가 다시 연속 2회 보이고, 출발 뒤 5초도 지난 경우에만 재반응한다. 안 보인 1초는 무시 시간 중에도 확인할 수 있다. |
| 사람이 보임 | 네 바퀴를 정지하고, 사람이 보이는 동안 정지를 유지한다. |
| 사람이 안 보임 | 새 인식 결과에서 사람이 연속 1초 동안 안 보이면 줄 따라가기를 다시 시작한다. 기다리는 중 다시 사람이 보이면 안 보인 시간을 다시 센다. |
| 사람과 STOP이 동시에 보이거나 STOP 정지 중 사람이 보임 | 사람 정지를 우선한다. 사람이 있어도 이미 시작한 STOP 3초·무시 5초는 계속 흐른다. STOP 정지가 끝나도 사람이 남아 있으면 재출발하지 않는다. 무시 시간은 실제 재출발 전에는 시작하지 않는다. |
| 표지·사람 때문에 정지한 동안 줄을 놓침 | 정지 중에는 줄 놓침 시간을 세지 않고 마지막 꺾기 방향을 유지한다. 재출발 때 줄이 없으면 그 시점부터 기존 02의 마지막 방향 1초 탐색을 적용한다. 꺾기 이력이 없으면 즉시 정지한다. 이미 줄 놓침으로 종료된 상태는 인식 결과가 돌아와도 재출발하지 않는다. |
| 아직 첫 인식 결과가 없거나 카메라·YOLO 결과가 오래됨 | 첫 결과 전에는 정지한다. 결과가 1초 넘게 갱신되지 않으면 정지하고 새 결과가 돌아오면 다른 정지 조건을 확인한 뒤 자동 재출발한다. 화면 순번이 바뀐 결과만 새 결과이며 유효 시간은 해당 화면을 인식하기 시작한 시각부터 센다. 끊긴 동안을 사람·STOP이 안 보인 시간으로 세지 않는다. 오래된 결과를 새로 관찰한 것으로 세지 않는다. |
| 주행 중 줄을 놓침 | 표지 정지와 겹치지 않는 경우 기존 02 규칙을 따른다. 마지막 꺾기 방향으로 최대 1초 찾고, 1초를 넘으면 정지한다. 꺾은 적이 없으면 즉시 정지하고, 줄 놓침 정지 뒤에는 자동 재출발하지 않는다. |
| 아무 키나 Ctrl+C 입력 | 즉시 정지하고 종료한다. |
| 정상 종료 또는 오류 발생 | 네 바퀴를 모두 0으로 정리한다. 기존 02처럼 정지 묶음을 0.2초 간격으로 3회 반복하고 바퀴 사이에 0.01초 간격을 둔다. 카메라·YOLO·녹화도 정리한다. |
| 출발 전 | 프로젝트 수칙에 따라 삐 소리를 낸다. 바퀴 실행 전에는 매번 사용자에게 안전 준비를 확인받는다. |
| 주행 기록 | 프로젝트 06 수칙에 따라 상태·센서 값·본 것을 표시한 블랙박스 영상을 `results/videos/`에, 회차·코드 버전·시도·완주·이탈·시간·손댄 횟수·메모를 `results/runs.csv`에 남긴다. 녹화는 기존 03의 15fps·시간 맞추기·파일 보관 규칙을 사용한다. 영상 글자는 영어·숫자만 사용하고 영상은 Git에서 제외한다. |

기존 근거: `specs/02-line.md`의 바닥 시험은 사용자 관찰 기준 5/5회 성공했다. `specs/05-signs.md`에서 같은 사진 30장을 640 모델로 재채점한 결과는 26/30이었다. 이 점수는 움직이면서 반응하는 이번 시험의 성능을 보장하는 수치는 아니다.

이번 지시서는 줄 따라가기와 사람·STOP 반응을 다룬다. 장애물 초음파 통합과 자동 완주 종료 조건은 이번 메모에서 정해지지 않았다.

## 성공 기준 (숫자로)
- STOP: 정지 유지 3초, 재출발 뒤 무시 시간 5초. 시간 허용 오차는 각각 ±0.5초이다.
- 사람: 보이는 동안 정지, 새 인식 결과에서 연속 1초 안 보이면 재출발. 시간 허용 오차는 ±0.5초이다.
- 대상이 카메라에 나타난 뒤 실제 정지까지 허용 시간은 1.5초이다. 제시된 시점부터 연속 2회 검출·명령 전달·실제 제동까지 포함한다.
- 시험 대상은 18cm 인쇄한 사람 사진과 9cm 인쇄 STOP 표지이다. 종이 트랙 직선 옆에 세워 로봇 앞 약 50cm에서 정면으로 보이게 한다. 실제 사람은 경로에 서지 않는다.
- STOP 정지·재출발·무시를 한 묶음으로 5번 중 4번 성공하면 통과한다.
- 사람 정지·기다림·재출발을 한 묶음으로 5번 중 4번 성공하면 통과한다.
- 사람과 STOP이 겹치는 시험은 3번 중 2번 성공하면 통과한다.
- 주행 시험은 기존 A4 종이 트랙(직선 6장·90도 곡선 4장, 약 1.1×0.85m) 한 바퀴이며 손댐·이탈 모두 0회이다. 한 바퀴 뒤 사용자가 키로 종료한다.
- 실제 바퀴의 전체 정지와 재출발은 사용자가 확인한다. 출력만으로 정상 판정하지 않는다.
- 2026-11-04 정식 바닥 시험: STOP 5회 → 사람 5회 → 동시 등장 3회 순서로, 매 회차 준비 확인을 받고 진행한다. 배터리를 고려해 회차마다 한 바퀴만 돌고 사용자가 Ctrl+C로 종료한다. 속도와 인식 규칙은 그대로 유지한다.
- 회차별 정지·재출발·무시/사람 우선 동작·손댐·이탈·종료 후 전체 정지를 사용자에게 확인받아 `results/runs.csv`에 남긴다. 기록에서 계산한 정지 명령 유지 시간도 남긴다. 이 시간은 실제 제동 시간이나 표지를 제시한 때부터의 반응 지연과 구별하며, 원시 기록만으로 알 수 없는 값은 미측정으로 둔다.

## 안전
- 직진 속도 50. 기존 02의 꺾기 최대 60을 유지한다. 프로젝트 절대 한계 150은 넘지 않는다.
- 바닥 시험 전 종이를 고정하고 로봇을 출발점에 맞춘 뒤 사방 1m를 비웠는지 사용자에게 확인받는다. 시험은 상자 위에서 네 바퀴가 모두 떠 있는지 확인받은 뒤 진행하고, 그다음 바닥에서 진행한다.
- 아무 키나 Ctrl+C로 즉시 정지한다. 오류가 나도 종료 정리에서 네 바퀴 0을 반복한다.
- 카메라 읽기·YOLO는 주행과 분리하며 오래된 화면을 쌓지 않는다. 영상 기록도 주행을 막지 않게 한다.
- 사람 시험은 18cm 인쇄 사진만 사용하며 실제 사람은 로봇 경로에 서지 않는다.
- 직전 바닥 시험에서 I2C 쓰기 오류 1회가 기록됐다. 다음 실제 주행 전 I2C 선·확장보드 전원을 확인하고 오류가 반복되면 원인을 확인한다.
- 프로그램은 `missions/06_drive_signs.py`이다. 상자 위 첫 시험을 마쳤고 사용자가 정식 바닥 시험을 요청했다. 매 회차 준비 확인 후 사용자 터미널에서 실행하며, 일괄 연속 실행하지 않는다.

## 바꿔 볼 값
- 모델: 기존 YOLO26n 640, 점수 기준 0.4 이상.
- 직진 속도: 50. 꺾기 30/60·15/60·0/60, 탐색 0/40 유지.
- STOP 정지 3초, 재출발 뒤 무시 5초, 사람 미검출 대기 1초.
- 검출 확인 연속 2회, 위치·크기 제한 없음(상자 높이 기록), 갱신 중단 1초 초과 시 정지.
- 사람 우선, STOP 시계는 사람 대기 중에도 진행, STOP 재반응 전 미검출 1초·출발 뒤 무시 5초, 정지 중 줄 놓침 시간 제외.
- 약 50cm 정면, STOP 9cm·사람 사진 18cm, STOP 4/5·사람 4/5·동시 2/3 이상, 실제 정지 1.5초 이내, 대기 시간 오차 ±0.5초.
