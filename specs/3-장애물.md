# 지시서 3 · 장애물 인식 정지

> **초안:** 사용자 요청(2026-11-04 「다 진행해 줘」)으로 Claude가 숫자와 규칙을 정했다. 조가 아직 확인하지 않았다. 고치려면 이 지시서부터 고치고 `tools/autodrive_core.py`의 `Config`를 맞춘다.

## 목표
줄을 따라가다 앞 물체가 가까우면 멈추고, 치우면 다시 간다. 이 단계에서 첫 기록(before)을 남긴다.

## 규칙표
| 상황 (언제) | 행동 (무엇을) |
|---|---|
| 초음파 15cm 이하 | 네 바퀴 0 · 파란 불 · 삐 0.2초 → 대기 |
| 대기 중 20cm 이상으로 멀어짐 | 다시 줄 따라 주행 (15~20cm 사이는 계속 대기 — 떨림 방지) |
| 초음파 0 이하만 1초 넘게 읽힘 | 비상 정지 (센서 고장으로 본다) |
| 줄 놓침 · 아무 키 · 오류 · 180초 경과 | 02-라인 · 5-오토드라이브와 같게 정지 |

거리는 최근 3개 값의 가운데 값을 쓴다. 값 하나가 튀어도 멈추거나 출발하지 않기 위해서다.

## 성공 기준 (숫자로)
- 벽 앞에서 15cm ±5cm 안에 멈춤 · 5번 중 5번.
- 첫 기록 5회를 `results/runs.csv`에 남김.

## 측정 규칙 (4회차에 확정하고 끝까지 그대로)
같은 트랙 · 같은 출발점 · 5회. 시간은 출발 삐부터 결승선 정지까지. 이탈은 프로그램이 센 값(줄을 0.1초 넘게 놓친 횟수). 완주와 손댄 횟수는 사람이 보고 입력.

## 안전
- 바퀴 속도 60 · 안쪽 30 (02-라인에서 조가 확정한 값).
- 실제 주행은 VS Code 터미널에서 직접 실행하고 「확인」을 입력해야 시작한다.

## 바꿔 볼 값
- 정지 거리 15cm → 25cm: 멈춘 간격과 흔들림 비교.

## 실행
`python3 missions/3_obstacle.py --drive --session 4 --attempt 1`
