# 지시서 6 · 트랙 주행 (카메라 차선 + 오토드라이브)

> **초안:** 사용자 요청(2026-11-05 「우리 판을 기반으로 작성」)으로 Claude가 썼다. 정지 규칙은 조가 쓰던 `specs/5-오토드라이브.md`의 초안 값이고, 차선 값은 3조 `specs/07-camera-lane.md` 값이다. 조가 아직 확인하지 않았고 실제 트랙에서 달려 보지 않았다. 3조의 13번 판은 쓰지 않는다.

## 목표
대구대 트랙(`specs/트랙-대구대.md`)에서 프로그램을 한 번 실행하면 노란 차선을 따라 달리고, 장애물·사람·STOP 앞에서 멈추며, 영상과 기록을 남긴다.

## 바탕
`missions/5_autodrive.py`와 같은 상태표·정지 처리·블랙박스·기록표를 쓴다. **조향 입력만 라인센서에서 카메라 차선으로 바꾼다.** 도로가 검은색이라 라인센서는 쓰지 않는다. `5_autodrive`의 동작은 바뀌지 않는다.

## 상태표
위에서 아래 순서로 먼저 맞는 줄을 따른다.

| 지금 상태 | 본 것 | 다음 상태 | 행동 |
|---|---|---|---|
| 모두 | 180초 경과 · 카메라 2초 멈춤 · 새 화면 0.5초 끊김 · 초음파 1초 고장 | EMERGENCY | 바퀴 0 · 빨간 불 · 삐 1초 · 종료 |
| 모두 | 아무 키 · Ctrl+C · 오류 | 종료 | 바퀴 0 |
| STOP_SIGN | 3초 안 지남 | STOP_SIGN | 바퀴 0 |
| WAIT_OBSTACLE | 20cm 안 됨 | WAIT_OBSTACLE | 바퀴 0 |
| WAIT_PERSON | 사람이 가깝거나 사라진 지 1초 안 됨 | WAIT_PERSON | 바퀴 0 |
| 주행 | 15cm 이하 | WAIT_OBSTACLE | 바퀴 0 · 파란 불 · 삐 0.2초 |
| 주행 | 사람 상자 높이 200px 이상 | WAIT_PERSON | 바퀴 0 · 빨간 불 · 삐 0.5초 |
| 주행 | STOP 표지 (재출발 뒤 5초는 무시) | STOP_SIGN | 바퀴 0 · 빨간 불 · 삐 0.2초 |
| 주행 | 처음부터 두 선이 다 안 보임 | EMERGENCY | 바퀴 0 · 종료 |
| 주행 | 한쪽 선만 보이고 차선 폭을 아직 모름 | 그대로 | 바퀴 0 · 두 선이 보일 때까지 대기 |
| 주행 | 두 선을 놓침 | 그대로 | 마지막에 꺾던 쪽으로 안쪽 0 · 바깥쪽 60 |
| 주행 | 두 선을 1초 동안 놓침 | EMERGENCY | 바퀴 0 · 종료 |
| 주행 | 그 밖 | FOLLOW | 왼쪽 = 35 + 0.4 × 오차, 오른쪽 = 35 − 0.4 × 오차 (0~80) · 초록 불 |

- 멈춰 있던 시간은 선 놓침 시간에 넣지 않는다. 재출발하면 새로 1초를 센다.
- 차선 찾기: 640×480 화면의 120~299줄에서 HSV H 15~40 · S 80 이상 · V 100 이상. x<320과 x≥320 각각 50점 이상이면 선으로 인정하고 x 평균을 쓴다. 오차 = 차선 중심 − 320.
- 결승선은 없다. 조가 어디서 끝날지 정하기 전까지 사람이 아무 키로 끝낸다(180초가 지나면 자동 정지).
- 감속(`기능-보행자제동`)은 끈다. 차선 기본 속도 35에 맞는 감속 값을 조가 아직 정하지 않았다.

## 카메라 각도
좌우 90 · 위아래 **5**로 시작한다. 2조 사진(`results/camera_tilt27.jpg`, `camera_tilt40.jpg`)에서 27도는 바닥이 화면 맨 아래에만, 40도는 거의 안 보여 차선을 볼 수 없다. 5는 3조가 자기 라즈봇에서 쓴 값이라 **2조 라즈봇에서 확인이 필요하다.** `--tilt`로 바꿀 수 있다. 낮게 내리면 사람 머리와 높이 있는 표지가 화면에서 잘릴 수 있다.

## 성공 기준 (숫자로)
- 조가 정할 것 (`specs/트랙-대구대.md`의 「조가 정할 것」과 같다).

## 안전
- 바퀴 값 0~80, 후진 없음. 코드에 150 초과 거부가 있다.
- 실제 주행은 VS Code 터미널에서 직접 실행하고 「확인」을 입력해야 시작한다. 끝나면(오류가 나도) 네 바퀴 0 · 부저와 불빛 끔.

## 아직 못 하는 것
- 갈림길 순서 고르기, 「천천히」·파랑·빨강 속도 바꾸기, 차단기 반응, 결승선 정지.
- 왼쪽·오른쪽 화면 절반의 평균만 쓰므로 모서리, 로터리, 횡단보도 옆길에서 잘못 꺾을 수 있다. 3조 기록에도 이 방식의 실제 코너 통과는 없다.
- 트랙의 초록 사람 모양은 상자가 200px까지 커지기 전에 놓칠 수 있다. 실제로 재 봐야 한다.

## 실행
- 바퀴 없이 차선 보기: `python3 missions/6_track.py --aim`으로 카메라만 맞춘 뒤 `python3 missions/07_camera_lane.py --check`. 각도를 바꾸려면 `--aim --tilt 10`.
- 가짜 센서 + 진짜 카메라: `python3 missions/6_track.py --simulate` (서보를 움직이지 않는다. `--aim` 먼저. 가짜 줄거리대로 잠깐씩 멈춘다.)
- 실제: `python3 missions/6_track.py --drive --session 회차 --attempt 시도`
- 초음파 없이: `--no-obstacle` · 각도 바꾸기: `--tilt 10`
- 바퀴 없이 시험: `python3 tools/test_track.py`
