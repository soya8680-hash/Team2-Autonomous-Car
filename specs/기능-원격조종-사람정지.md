# 지시서 · 원격 조종 + 사람 앞 자동 정지

사용자 요청(2026-11-04): 원격으로 조종하되 사람이 가까워지면 자동으로 멈춘다.
요청은 「반경 35m」였으나 카메라로 잴 수 없어 **35cm**로 해석했다. 사용자 확인 대기.
상자 높이 기준과 속도는 Claude 초안이다.

## 목표
노트북 키보드로 조종하다가 앞에 사람이 가까우면 사람의 조작보다 먼저 멈춘다.

## 규칙표
| 상황 (언제) | 행동 (무엇을) |
|---|---|
| w/s/a/d/q/e 누름 | 그 방향으로 움직임. 손을 떼면 0.6초 뒤 정지 |
| 스페이스 · x | 정지 · 끝내기 |
| +/- | 속도 ±20 (40~100, 시작 60) |
| 사람 (점수 0.5 이상 · 상자 높이 350px 이상 · 연속 2번) | 즉시 정지 · 빨간 불 · 삐 0.5초 · 잠금 |
| 잠금 중 이동 키 | 전부 무시 (뒤로 가기도 막음) |
| 사람이 1초 동안 안 보임 | 잠금 풀림 · 초록 불. 저절로 출발하지 않음 |
| 카메라나 YOLO 결과가 1초 넘게 멈춤 | 정지 · 잠금 (사람을 볼 수 없으므로) |
| Ctrl+C · 오류 · 연결 끊김 | 정지하고 끝 |

## 성공 기준 (숫자로)
- 사람 앞 35cm ±10cm에서 멈춤 · 5번 중 5번. 사용자가 자로 잰다.

## 안전
- 바퀴 속도 100 이하.
- **「반경」이 아니다.** 카메라가 보는 앞쪽만 안다. 옆과 뒤의 사람, 벽, 의자에는 멈추지 않는다.
- 거리를 재는 것이 아니라 상자 높이로 짐작한다. 앉은 사람, 가려진 사람은 다르게 나올 수 있다.
- 터미널에서 직접 실행하고 「확인」을 입력해야 시작한다.

## 바꿔 볼 값
- 상자 높이 350px: 35cm에 서서 실제 값을 재고 맞춘다 (`python3 missions/4_yolo.py`가 `h=` 값을 보여 준다).

## 실행
- 바퀴 없이: `python3 missions/guarded_teleop.py --dry`
- 실제: `python3 missions/guarded_teleop.py --drive`
