# 지시서 · 원격 조종 + 사람 앞 자동 정지

사용자 요청(2026-11-04): 원격으로 조종하되 사람이 가까워지면 자동으로 멈춘다.
사용자 재확인(2026-11-04): **35미터**가 맞다. 기존의 35cm 해석은 잘못이므로 폐기한다.
현재 카메라/YOLO 출력은 종류·점수·화면 좌표뿐이며 미터 단위 거리 측정값은 없다.
350px 기준은 35m 기준이 아니다. 사용자 선택(2026-11-04): **거리와 무관하게 사람이 인식되면 정지**하도록 수정한다.
35m 거리 판별이나 35m에서의 인식 성능을 보장하는 기능은 아니다.

## 목표
노트북 키보드로 조종하다가 카메라에 사람이 인식되면 거리·상자 크기에 관계없이 사람의 조작보다 먼저 멈춘다.

## 규칙표
| 상황 (언제) | 행동 (무엇을) |
|---|---|
| w/s/a/d/q/e 누름 | 그 방향으로 움직임. 손을 떼면 0.6초 뒤 정지 |
| 스페이스 · x | 정지 · 끝내기 |
| +/- | 속도 ±20 (40~100, 시작 60) |
| 사람 (점수 0.5 이상 · 상자 크기 무관 · 첫 인식부터) | 즉시 정지 · 빨간 불 · 삐 0.5초 · 잠금 |
| 첫 카메라/인식 결과 전 이동 키 | 전부 무시 |
| 잠금 중 이동 키 | 전부 무시 (뒤로 가기도 막음) |
| 사람이 1초 동안 안 보임 | 잠금 풀림 · 초록 불. 저절로 출발하지 않음 |
| 카메라나 YOLO 결과가 1초 넘게 멈춤 | 정지 · 잠금 (사람을 볼 수 없으므로) |
| Ctrl+C · 오류 · 연결 끊김 | 정지하고 끝 |

## 글자 명령으로 조종 (`missions/cmd_drive.py`)
사용자 요청(2026-11-04): 터미널에 명령을 쳐서 움직인다. 위 규칙의 잠금과 정지를 그대로 쓴다.

| 입력 | 행동 |
|---|---|
| `w 2` (앞) · `s 2` (뒤) · `a 2` · `d 2` (옆) · `q 2` · `e 2` (제자리 회전) | 숫자만큼 초 단위로 움직이고 정지. 숫자를 빼면 1초, 최대 5초. forward · back · left · right · turnleft · turnright 도 된다 |
| `speed 80` | 속도 40~100으로 바꿈 |
| `stop` · `quit` | 정지 · 끝내기 |
| 그 밖의 입력, 범위를 넘는 숫자 | 거절 · 움직이지 않음 |
| 움직이는 중 아무 키 | 바로 정지 |
| 움직이기 전 또는 도중에 사람이 인식됨 | 움직이지 않음 또는 정지 · 잠금 이유 출력 |

## 성공 기준 (숫자로)
- 작은 사람·큰 사람 모두 첫 유효 인식에서 정지 명령을 보내고 모든 이동 키를 차단한다.
- 요청 거리: 35m. 사용자 선택에 따라 거리 무관 인식 정지로 변경. 35m 감지·실제 정지는 미검증.
- 성공 횟수·허용 오차·정지 시간 기준: 사용자 결정 필요.

## 안전
- 바퀴 속도 100 이하.
- **「반경」이 아니다.** 카메라가 보는 앞쪽만 안다. 옆과 뒤의 사람, 벽, 의자에는 멈추지 않는다.
- 거리 측정·상자 높이 제한 없음. 카메라가 놓치거나 모델이 사람으로 인식하지 못하면 사람 정지는 작동하지 않을 수 있다.
- 터미널에서 직접 실행하고 「확인」을 입력해야 시작한다.

## 바꿔 볼 값
- 기존 상자 높이 350px는 거리 측정값이 아니며, 35m로 환산하지 않는다.

## 실행
- 바퀴 없이: `python3 missions/guarded_teleop.py --dry`
- 실제: `python3 missions/guarded_teleop.py --drive`
- 글자 명령: `python3 missions/cmd_drive.py --drive` (바퀴 없이: `--dry`)
