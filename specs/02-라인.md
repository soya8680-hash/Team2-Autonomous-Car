# 지시서 02 · 라인 따라가기

## 목표
2조 라즈봇이 검은 줄을 따라 직선과 곡선을 손대지 않고 한 번씩 통과한다.
출처: 「라즈봇 자율주행 미션 안내」 2단계. 사용자가 1단계 이후 다음 단계 진행을 요청했다.

## 규칙표
사용자가 아래 규칙과 속도·시간을 확정했다. 코드 준비 후 트랙을 마련했고, 센서 확인 완료 및 다음 시험 진행을 요청했다.

| 상황 (언제) | 행동 (무엇을) |
|---|---|
| 가운데 줄 감지 | 네 바퀴 속도 60으로 직진 |
| 왼쪽 줄 감지 | 왼쪽 두 바퀴 30, 오른쪽 두 바퀴 60으로 좌회전 |
| 오른쪽 줄 감지 | 왼쪽 두 바퀴 60, 오른쪽 두 바퀴 30으로 우회전 |
| 네 센서 모두 검정 | 정지 |
| 줄 놓침 | 비상 정지 (공통 미션 필수) |
| 아무 키 입력·오류·종료 | 네 바퀴 모두 정지 (공통 미션 필수) |
| 시작 후 10초 경과 | 정지하고 종료 |

센서 해석: 검정은 0, 왼쪽부터 x2·x1·x3·x4. 검정을 감지한 위치에 왼쪽부터 -3·-1·1·3을 부여해 합이 음수면 왼쪽, 양수면 오른쪽, 0이면 가운데로 판단한다. 네 칸 모두 검정 또는 모두 흰색은 먼저 정지로 처리한다. 사용자는 센서 확인 완료를 알렸다. 저장 기록에서는 네 채널의 흑백 변화가 확인됐으나 물리적 좌우 순서 자체는 기록만으로 확정할 수 없다.

## 성공 기준 (숫자로)
- 직선 1회, 곡선 1회 손대지 않고 통과 (공통 미션 기준).
- 실제 통과 여부는 사용자가 관찰해 확인한다.

## 안전
- 바퀴 속도는 150 이하. 첫 시험 기본 속도 60, 회전 안쪽 30·바깥쪽 60으로 확정.
- 첫 시험 최대 10초로 확정.
- 기본 실행은 가상 센서 검사만 수행한다. 실제 주행은 `--drive` 선택 후 터미널에서 준비 확인을 입력해야 시작한다.
- 실제 주행 중 키보드로 즉시 정지할 수 있도록 대화형 터미널이 없으면 주행을 시작하지 않는다.
- 바퀴가 도는 시험 전 바닥·사방 1m 확보를 사용자가 확인해야 한다.
- 바퀴를 움직이지 않는 센서 점검으로 왼쪽부터 x2·x1·x3·x4 배치를 먼저 확인한다.

## 바꿔 볼 값
- 조가 정할 항목: 주행 관찰 후 속도 또는 회전 세기 변경 실험.
