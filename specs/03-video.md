# 지시서 03 · 블랙박스 영상

> **3조 지시서를 가져옴** (github.com/jihooni217/raspbot-pbl-3team @ 7e8a30d, 2026-11-05). 규칙과 숫자는 3조가 정한 값이고 **2조가 아직 확인하지 않았다.** 아래 「결과」 표의 기존 줄은 3조 기록이며 2조 라즈봇·트랙에서 나온 결과가 아니다.

## 목표
바퀴를 움직이지 않고 카메라 영상을 날짜·시간 및 상태 글자와 함께 녹화한다. 이후 YOLO와 자동 주행이 같은 최신 카메라 화면을 나눠 쓸 수 있게 만든다.

## 규칙표
| 상황 (언제) | 행동 (무엇을) |
|---|---|
| 프로그램 시작 | tools/yolo.py의 open_camera()로 카메라를 연다. 기존 함수의 640×480·30fps(MJPG) 설정을 사용한다. |
| 카메라 화면 읽기 | 카메라 읽기는 스레드 하나만 맡고, 가장 최근 화면만 보관한다. 나중에 YOLO와 자동 주행이 이 화면을 읽어 쓸 수 있게 구성한다. 이번에는 YOLO나 자동 주행을 실행하지 않는다. |
| 영상 녹화 | 최신 화면을 초당 15장 선택해 results/videos/에 H.264(avc1) mp4로 저장한다. 파일 이름 앞에 blackbox_를 붙인다. 한 장씩 바로 파일에 쓰고 영상 전체를 모아 두지 않는다. |
| 촬영과 저장 속도 맞추기 | 새 화면이 늦게 들어와도 마지막 화면을 다시 써서 초당 15장을 채운다. 재생 시간은 실제 녹화 경과 시간과 같게 유지한다. |
| 영상 위 날짜·시간 | 왼쪽 위에 2026-11-03 17:55:12 형식으로 표시한다. 한글 없이 숫자와 날짜·시간 구분 기호를 사용한다. |
| 영상 위 상태 글자 | 아래에 REC를 표시한다. 나중에 자동 주행에서 상태 글자를 바꿀 수 있도록 외부에서 변경할 수 있게 만든다. 상태 글자는 영어와 숫자만 사용한다. |
| 녹화 1분 경과 | 현재 파일을 정상적으로 닫고 새 파일에 이어서 저장한다. |
| 보관 파일이 30개를 넘음 | 이 프로그램이 만든 blackbox_로 시작하는 mp4만 세고, 그중 최근 30개만 남겨 오래된 파일부터 삭제한다. 다른 파일은 세거나 삭제하지 않는다. |
| Ctrl+C 입력 | 녹화를 멈추고 영상 파일을 정상적으로 닫으며, 카메라 읽기 스레드와 카메라를 정리하고 종료한다. |
| 구현 후 기본 시험 | 10초 실행하고 종료해 파일 생성·파일 크기·경로·실제 영상 길이가 9~11초인지 확인해 보고한다. |
| 분할·보관 시험 | 시험할 때만 분할 5초·보관 3개로 바꿔 20초 실행한다. 파일이 분할되고 blackbox_ mp4가 3개만 남는지 확인한다. 시험 뒤 기본값은 분할 60초·보관 30개를 유지한다. |

## 성공 기준 (숫자로)
- 저장은 15fps이며 새 화면이 부족하면 마지막 화면을 반복 저장해 실제 경과 시간과 같은 속도로 재생되어야 한다.
- 1분마다 파일이 나뉘고 최근 30개만 남아야 한다.
- 10초 시험에서 mp4 파일이 생성되고 정상적으로 열려야 한다. 파일 크기·경로·영상 길이를 보고한다.
- 10초 시험 영상의 재생 길이가 9~11초이면 통과한다.
- Ctrl+C 종료 후 파일이 정상 재생되어야 한다.
- 분할 5초·보관 3개 설정으로 20초 시험한 뒤 blackbox_ mp4가 3개만 남으면 분할·보관 시험을 통과한다.
- 날짜·시간과 REC 글자가 영상에 보이고, 상태 글자를 외부에서 변경할 수 있어야 한다.

## 안전
- 바퀴는 움직이지 않는다. 모터·서보 동작을 추가하지 않는다.
- 영상은 results/videos/에 저장하며 Git에 올리지 않는다(기존 프로젝트 수칙).
- 자동 삭제는 이 프로그램이 만든 blackbox_로 시작하는 mp4에만 적용한다. 다른 이름의 영상이나 파일은 삭제하지 않는다.
- models/ 파일은 변경하거나 삭제하지 않는다. 새 모델·큰 패키지를 설치하지 않는다.

## 바꿔 볼 값
- 기본값: 저장 15fps, 파일 분할 60초, 보관 30개.
- 현재 상태 글자: REC. 외부에서 변경할 수 있게 만든다.
- 날짜·시간: YYYY-MM-DD HH:MM:SS (예: 2026-11-03 17:55:12).
- 새 화면 부족 시 마지막 화면을 반복해 15fps를 채운다.
- 삭제 범위: 이 프로그램이 만든 blackbox_ 접두사의 mp4만.
- 기본 시험: 10초 실행, 재생 길이 9~11초 통과.
- 분할·보관 시험: 분할 5초, 보관 3개, 20초 실행, 최종 파일 3개 확인.
