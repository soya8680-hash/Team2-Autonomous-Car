# 2단계 코드 준비 검사 — 2026-11-04

정상: 코드와 가상 검사를 완료했다. 실제 주행 성능 판정은 아직 하지 않았다.

사용자 확정: 기본 속도 60, 회전 안쪽 30·바깥쪽 60, 최대 10초. 트랙 없이 코드 준비만 진행.

## 실행과 결과

- `python3 missions/02_line.py`: 센서 조합 16가지의 방향·정지 판단 출력 확인. 장치 접근 없음.
- `python3 tools/test_line_logic.py`: 7개 검사 통과.
  - 16개 센서 조합의 판단과 속도 상한.
  - 줄 놓침 때 정지.
  - 키 입력 때 이동 전 정지.
  - 센서 통신 오류·중단 때 네 바퀴 정지 시도.
  - 한 바퀴 정지 명령이 실패해도 나머지 바퀴 정지 시도.
  - 센서 읽기 도중 시간 제한이 지나면 이동 금지.
  - 일부 모터 명령 전송 후 오류가 나면 네 바퀴 정지 시도.

## 실제 시험 전 남은 일

- 밝은 바닥과 검은 테이프 준비.
- 센서 왼쪽부터 x2·x1·x3·x4 배치를 한 칸씩 확인.
- 바닥·사방 1m 확보 확인 후 최초 저속 시험.
- 직선 1회·곡선 1회 손대지 않고 통과하는지 사용자 관찰.
- 아무 키 정지와 실제 네 바퀴 정지 확인.

일반 실행은 가상 검사만 수행한다. 실제 주행은 `--drive` 및 대화형 준비 확인이 필요하다. 이번에는 센서·바퀴 명령을 전송하지 않았다.
